# GUSTÓ · Carrusel DAK Burger: la tipografía se transforma con cada burger

**Por qué gustó:** cada diapositiva tiene un mecanismo propio que nace del producto. Las letras aplastadas como una smash burger gotean como el cheddar; la torre se lee como un rascacielos; la burger con polvo lunar va con un arco orbital. El mismo rojo anaranjado #FF3B1F y el mismo flash nocturno.
